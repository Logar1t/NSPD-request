## Инициализация

### `__init__(timeout=30)`

Инициализирует экземпляр класса NSPD.

**Параметры:**
- `timeout` (int, опционально): Таймаут для запросов в секундах. По умолчанию: 30

**Возвращает:**
- Экземпляр класса `NSPD`

**Пример использования:**
```python
from nspd_request import NSPD

# Создание экземпляра с таймаутом по умолчанию
api = NSPD()

# Создание экземпляра с кастомным таймаутом
api = NSPD(timeout=60)
```

## Получение кадастровых данных по координатам

### `get_cadastral_districts(lat, lon, size_meters=100)`

Получает данные о кадастровых округах по координатам. Выполняет WMS GetFeatureInfo запрос к слою кадастровых округов.

**Параметры:**
- `lat` (float): Широта в градусах (WGS84, EPSG:4326)
- `lon` (float): Долгота в градусах (WGS84, EPSG:4326)
- `size_meters` (float, опционально): Размер BBOX в метрах. По умолчанию: 100

**Возвращает:**
- `dict` или `None`: JSON данные с информацией о кадастровых округах или `None` в случае ошибки

**Структура возвращаемых данных:**
```python
{
    "features": [
        {
            "type": "Feature",
            "id": "уникальный_id",
            "geometry": {
                "type": "Polygon" или "MultiPolygon",
                "coordinates": [[[x, y], ...]]  # Координаты в EPSG:3857
            },
            "properties": {
                "descr": "77...",  # Описание округа
                "options": {
                    # Дополнительные опции
                }
            }
        },
        ...
    ]
}
```

**Пример использования:**
```python
result = api.get_cadastral_districts(55.7558, 37.6173, size_meters=100)
if result:
    features = result.get('features', [])
    print(f"Найдено округов: {len(features)}")
    if features:
        first = features[0]
        print(f"Описание: {first.get('properties', {}).get('descr', 'N/A')}")
```

📖 **См. также:** [Примеры использования в README.md](README.md#получение-кадастровых-данных-по-координатам)

### `get_cadastral_regions(lat, lon, size_meters=1)`

Получает данные о кадастровых районах по координатам. Выполняет WMS GetFeatureInfo запрос к слою кадастровых районов.

**Параметры:**
- `lat` (float): Широта в градусах (WGS84)
- `lon` (float): Долгота в градусах (WGS84)
- `size_meters` (float, опционально): Размер BBOX в метрах. По умолчанию: 1

**Возвращает:**
- `dict` или `None`: JSON данные с информацией о кадастровых районах или `None` в случае ошибки

**Структура возвращаемых данных:**
```python
{
    "features": [
        {
            "type": "Feature",
            "id": "уникальный_id",
            "geometry": {
                "type": "Polygon" или "MultiPolygon",
                "coordinates": [[[x, y], ...]]  # Координаты в EPSG:3857
            },
            "properties": {
                "descr": "77:03",  # Кадастровый номер района
                "options": {
                    "cnt_land_geom": 11618,  # Количество ЗУ в районе
                    "cnt_oks_geom": 23350,   # Количество ОКС в районе
                    # Дополнительные опции
                }
            }
        },
        ...
    ]
}
```

**Примечание:** Автоматически фильтрует районы, заканчивающиеся на `:00` (несуществующие районы)

**Пример использования:**
```python
result = api.get_cadastral_regions(55.7558, 37.6173, size_meters=1)
if result:
    features = result.get('features', [])
    print(f"Найдено районов: {len(features)}")
    if features:
        first = features[0]
        props = first.get('properties', {})
        options = props.get('options', {})
        print(f"Кадастровый номер района: {props.get('descr', 'N/A')}")
        print(f"ЗУ в районе: {options.get('cnt_land_geom', 0)}")
        print(f"ОКС в районе: {options.get('cnt_oks_geom', 0)}")
```

## Работа с кадастровыми номерами

### `search_by_cadastral_number(kad_number)`

Получает полные данные из НСПД по кадастровому номеру. Выполняет поиск объекта в базе данных НСПД.

**Параметры:**
- `kad_number` (str): Кадастровый номер в формате "XX:XX:XXXXXXX:XXXX"

**Возвращает:**
- `dict`: Словарь с данными из НСПД или словарь с ключом `error` в случае ошибки

**Структура возвращаемых данных (при успехе):**
```python
{
    "kad_number": "77:03:0002007:7190",  # Добавлено автоматически
    "geom_id": "426710013",              # Извлечено автоматически (если найдено)
    "data": {
        "features": [
            {
                "type": "Feature",
                "id": "426710013",
                "geometry": {
                    "type": "Polygon",
                    "coordinates": [[[x, y], ...]]  # Координаты в EPSG:3857
                },
                "properties": {
                    # Свойства объекта
                }
            }
        ]
    },
    "meta": [
        {
            "categoryId": "36368",  # ID категории (36368=ЗУ, 36369=Здание, и т.д.)
            # Дополнительные метаданные
        }
    ],
    # Другие поля из ответа НСПД
}
```

**Структура при ошибке:**
```python
{
    "error": "Описание ошибки"
}
```

**Пример использования:**
```python
result = api.search_by_cadastral_number("77:03:0002007:7190")
if "error" in result:
    print(f"Ошибка: {result['error']}")
else:
    print(f"Geom ID: {result.get('geom_id')}")
    print(f"Кадастровый номер: {result.get('kad_number')}")
    # Доступ к полным данным
    if 'data' in result and 'features' in result['data']:
        features = result['data']['features']
        print(f"Найдено features: {len(features)}")
```

### `get_object_info(kad_number, include_geom_id=False, include_object_type=False, include_related=False)`

Универсальная функция для получения информации об объекте с возможностью включения дополнительных полей.

**Параметры:**
- `kad_number` (str): Кадастровый номер
- `include_geom_id` (bool, опционально): Включить geom_id в результат. По умолчанию: False
- `include_object_type` (bool, опционально): Включить точный тип объекта в результат. По умолчанию: False
- `include_related` (bool, опционально): Включить связанные объекты в результат. По умолчанию: False

**Возвращает:**
- `dict`: Словарь с данными и дополнительными полями (если запрошены)
  - Всегда содержит базовые данные из НСПД
  - При `include_geom_id=True`: добавляет ключ `geom_id`
  - При `include_object_type=True`: добавляет ключ `object_type` с точным типом
  - При `include_related=True`: добавляет ключ `related` со списком связанных объектов

**Пример использования:**
```python
# Только базовые данные
data = api.get_object_info("77:03:0002007:7190")

# С geom_id и типом объекта
data = api.get_object_info("77:03:0002007:7190", 
                          include_geom_id=True, 
                          include_object_type=True)

# Полная информация со связанными объектами
data = api.get_object_info("77:03:0002007:7190",
                          include_geom_id=True,
                          include_object_type=True,
                          include_related=True)
if "related" in data:
    print(f"Связанных объектов: {len(data['related'])}")
```

📖 **См. также:** [Примеры использования в README.md](README.md#получение-информации-об-объекте)

## Получение связанных объектов

### `get_land_plots_by_oks(geom_id, debug=False)`

Получает список ЗУ (Земельных участков) по geomId ОКС (Объект капитального строительства). Работает для всех типов ОКС: Здание, Сооружение, Объект незавершенного строительства. Выполняет запрос к НСПД для получения связанных земельных участков.

**Параметры:**
- `geom_id` (str): ID геометрии ОКС
- `debug` (bool, опционально): Включить отладочную информацию. По умолчанию: False

**Возвращает:**
- `list` или `None`: Список кадастровых номеров ЗУ в формате строк или `None` в случае ошибки

**Структура возвращаемых данных:**
```python
[
    "77:03:0002007:7190",  # Кадастровый номер первого ЗУ
    "77:03:0002007:7191",  # Кадастровый номер второго ЗУ
    ...
]
```

**Пример использования:**
```python
geom_id = "107797780"
zu_list = api.get_land_plots_by_oks(geom_id, debug=False)
if zu_list:
    print(f"Найдено ЗУ: {len(zu_list)}")
    for zu in zu_list:
        print(f"  - {zu}")
        # Можно использовать для дальнейших запросов
        zu_info = api.search_by_cadastral_number(zu)
```

### `get_related_objects(kad_number, debug=False)`

Получает связанные объекты по кадастровому номеру. Автоматически определяет тип объекта и получает соответствующие связанные объекты.

**Параметры:**
- `kad_number` (str): Кадастровый номер
- `debug` (bool, опционально): Включить отладочную информацию. По умолчанию: False

**Возвращает:**
- `dict`: Словарь с данными объекта и связанными объектами

**Структура возвращаемых данных (при успехе):**
```python
{
    "data": {
        # Полные данные объекта из НСПД (структура как в search_by_cadastral_number)
        "kad_number": "77:03:0002007:7190",
        "geom_id": "426710013",
        "data": {...},
        "meta": [...]
    },
    "geom_id": "426710013",  # Извлеченный ID геометрии
    "type": "ЗУ",  # Определенный тип объекта: "ЗУ", "Здание", "Сооружение", "Объект незавершенного строительства"
    "related": [
        "77:03:0002007:9137",  # Кадастровый номер первого связанного объекта
        "77:03:0002007:9561",  # Кадастровый номер второго связанного объекта
        ...
    ],
    "error": None  # Ошибок нет
}
```

**Структура при ошибке:**
```python
{
    "data": None,
    "geom_id": None,
    "type": None,
    "related": [],
    "error": "Описание ошибки"
}
```

**Логика работы:**
- Для ЗУ: получает список связанных ОКС (всех типов: Здание, Сооружение, ОНС)
- Для всех типов ОКС (Здание, Сооружение, ОНС): получает список связанных ЗУ

**Пример использования:**
```python
result = api.get_related_objects("77:03:0002007:7190", debug=False)
if result.get("error"):
    print(f"Ошибка: {result['error']}")
else:
    print(f"Тип объекта: {result['type']}")
    print(f"Geom ID: {result['geom_id']}")
    print(f"Связанных объектов: {len(result['related'])}")
    for obj in result['related']:
        print(f"  - {obj}")
        # Можно получить информацию о каждом связанном объекте
        obj_info = api.get_object_type(obj)
        print(f"    Тип: {obj_info}")
```

### `get_by_coordinates(latitude, longitude, object_type='land_plot', bbox_size=0.05)`

Универсальная функция для получения кадастрового номера по координатам.

**Параметры:**
- `latitude` (float): Широта в градусах (WGS84)
- `longitude` (float): Долгота в градусах (WGS84)
- `object_type` (str, опционально): Тип объекта. По умолчанию: 'land_plot'
  - `'land_plot'` или `'zu'`: для поиска ЗУ
  - `'oks'`: для поиска ОКС (любого типа)
- `bbox_size` (float, опционально): Размер BBOX в метрах. По умолчанию: 0.05

**Возвращает:**
- `str` или `None`: Кадастровый номер или `None` в случае ошибки

**Пример использования:**
```python
# Поиск ЗУ
zu_number = api.get_by_coordinates(55.811978, 37.498339, object_type='land_plot')

# Поиск ОКС
oks_number = api.get_by_coordinates(55.756126, 37.615042, object_type='oks')
```

## Grid

### `get_grid_data(lat, lon, boundary_type='kr', category_id=36368, verbose=False)`

Выгружает список выбранных объектов по выбранному слою (категории), которые находятся в границах, определенных по координатам. 

**Как работает:**
1. По координатам определяет границы (кадастровый район, квартал или округ)
2. Извлекает полигоны границ из полученных данных
3. Автоматически разбивает большие полигоны на части для оптимизации запросов
4. Для каждой части полигона делает запрос к grid с указанной категорией объектов
5. Объединяет все результаты и фильтрует дубликаты
6. Возвращает полный список объектов выбранной категории в указанных границах

**Параметры:**
- `lat` (float): Широта в градусах (WGS84) - точка для определения границ
- `lon` (float): Долгота в градусах (WGS84) - точка для определения границ
- `boundary_type` (str, опционально): Тип границы для определения области поиска. По умолчанию: 'kr'
  - `'kr'`: Кадастровый район (самый детальный уровень)
  - `'kk'`: Кадастровый квартал (средний уровень)
  - `'ko'`: Кадастровый округ (самый широкий уровень)
- `category_id` (int, опционально): ID категории объектов для выгрузки. По умолчанию: 36368 (ЗУ)
  - `36368`: ЗУ (Земельный участок)
  - `36369`: Здание (ОКС)
  - `36383`: Сооружение (ОКС)
  - `36384`: Объект незавершенного строительства (ОКС)
- `verbose` (bool, опционально): Выводить ли подробную информацию о процессе. По умолчанию: False

**Возвращает:**
- `dict` или `None`: FeatureCollection с результатами запросов или `None` в случае ошибки

**Структура возвращаемых данных:**
```python
{
    "type": "FeatureCollection",
    "features": [
        {
            "type": "Feature",
            "id": "106608691",  # Уникальный ID объекта
            "geometry": {
                "type": "Polygon" или "MultiPolygon",
                "coordinates": [[[x, y], ...]]  # Координаты границ объекта в EPSG:3857
            },
            "properties": {
                "options": {
                    "cad_num": "77:03:0002007:7190",  # Кадастровый номер
                    "categoryId": "36368",            # ID категории
                    # Другие свойства объекта
                },
                # Дополнительные свойства
            }
        },
        {
            # Следующий объект
        },
        ...
    ]
}
```

**Особенности:**
- Автоматически извлекает полигоны границ из слоя (район/квартал/округ)
- Разбивает большие полигоны на части для оптимизации запросов (чтобы избежать таймаутов)
- Автоматически определяет оптимальное количество частей на основе количества объектов в границах
- Делает множественные запросы к grid для каждой части полигона
- Фильтрует дубликаты по `id` и `cad_num`
- Возвращает только уникальные объекты
- Не сохраняет файл автоматически (данные только возвращаются)

**Пример использования:**
```python
# Получение всех ЗУ в кадастровом районе
result = api.get_grid_data(
    lat=55.770783,
    lon=37.73718,
    boundary_type='kr',      # Используем границы кадастрового района
    category_id=36368,        # Выгружаем только ЗУ
    verbose=True              # Показывать прогресс
)

if result:
    features = result.get('features', [])
    print(f"Найдено ЗУ в районе: {len(features)}")
    
    # Обработка каждого объекта
    for feature in features[:10]:  # Первые 10
        properties = feature.get('properties', {})
        options = properties.get('options', {})
        cad_num = options.get('cad_num', 'N/A')
        print(f"  - {cad_num}")
    
    # Сохранение в файл (если нужно)
    from nspd_request import save_json_to_file
    save_json_to_file(result, 'all_zu_in_region.json')

# Получение всех зданий в кадастровом квартале
buildings = api.get_grid_data(
    lat=55.770783,
    lon=37.73718,
    boundary_type='kk',      # Используем границы кадастрового квартала
    category_id=36369,       # Выгружаем только Здания
    verbose=True
)
```

📖 **См. также:** [Примеры использования в README.md](README.md#массовая-выгрузка-через-grid)

**Примечание:** Для сохранения результата в файл используйте функцию `save_json_to_file` из модуля `utils`.

## Типы объектов

## Обработка ошибок

Все методы возвращают понятные значения при ошибках:

- Методы, возвращающие `str`: возвращают `None` при ошибке
- Методы, возвращающие `list`: возвращают `None` при ошибке
- Методы, возвращающие `dict`: содержат ключ `error` с описанием ошибки

**Пример обработки ошибок:**
```python
# Для методов, возвращающих None при ошибке
geom_id = api.get_geom_id("неверный_номер")
if geom_id is None:
    print("Ошибка: не удалось получить geom_id")

# Для методов, возвращающих dict с ошибкой
result = api.search_by_cadastral_number("неверный_номер")
if "error" in result:
    print(f"Ошибка: {result['error']}")

# Для get_related_objects
result = api.get_related_objects("неверный_номер")
if result.get("error"):
    print(f"Ошибка: {result['error']}")
```

## Примечания

1. Все координаты должны быть в формате WGS84 (EPSG:4326)
2. Кадастровые номера должны быть в формате "XX:XX:XXXXXXX:XXXX"
3. Методы автоматически преобразуют координаты из WGS84 в EPSG:3857 для запросов
4. При работе с большими объемами данных используйте параметр `verbose=True` для отслеживания прогресса
5. Для сохранения результатов Grid используйте функцию `save_json_to_file` из модуля `utils`
